# Mapa systemu przeciwdziałania greenwashingowi

## Definicja robocza

**ESA (ESMA/EBA/EIOPA, 2023–2024):** greenwashing to praktyka, w której oświadczenia, deklaracje, działania lub komunikacja związane ze zrównoważonym rozwojem **nie odzwierciedlają jasno i rzetelnie** rzeczywistego profilu zrównoważonego podmiotu, produktu finansowego lub usługi i **mogą wprowadzać w błąd** konsumentów, inwestorów lub innych uczestników rynku. Może być zamierzone albo niezamierzone; zamiar, niedbalstwo lub brak due diligence to czynniki obciążające przy egzekwowaniu.

**ECGT (dyrektywa 2024/825)** definiuje **twierdzenie dotyczące ekologiczności** jako każdy dobrowolny komunikat handlowy (tekst, grafika, znak, nazwa marki/produktu), który stwierdza lub sugeruje pozytywny wpływ na środowisko, brak wpływu, mniejszą szkodliwość albo poprawę w czasie.

## Hierarchia stosowania (produkt / usługa / komunikacja)

```
1. Czy twierdzenie jest obowiązkowe z mocy prawa?
   TAK → to nie jest „green claim”; i tak nie wolno go przedstawiać jako cechy wyróżniającej (ECGT 10a).
   NIE → idź dalej.

2. Czy termin jest zastrzeżony sektorowo?
   Żywność „eko/bio/organic”     → tylko 2018/848 + ustawa PL.
   Fundusz „ESG / sustainable”   → wytyczne ESMA nazw + SFDR art. 8/9 + Taksonomia.
   Budynek „bezemisyjny”         → definicja EPBD art. 11, nie certyfikat BREEAM/LEED.
   Transport „ślad CO2 przesyłki”→ CountEmissionsEU + ISO 14083, jeśli ujawniane.

3. Relacja z odbiorcą
   Konsument (B2C)  → UPNPR (już) + ECGT od 27.09.2026 (UE) + nowela PL (Sejm: 27.09.2027, Senat w toku) + kary UOKiK.
   Kontrahent/B2B   → UZNK (oznaczenia, reklama) + roszczenia cywilne.
   Inwestor         → SFDR / Taksonomia / wytyczne ESA + „fair, clear and not misleading”.

4. Test ogólny (zawsze)
   Prawda + pełny zakres + istotność + dowód + brak offsetu jako „neutralności”
   + certyfikat tylko z systemu spełniającego definicję ECGT.
```

## Dwa reżimy UE na twierdzenia ekologiczne

| | **ECGT 2024/825** | **Green Claims COM(2023) 166** |
|---|---|---|
| Status IX 2026 | Prawo UE; stosowanie 27.09.2026 | Wniosek wstrzymany (VI 2025); nie prawo |
| Mechanizm | Czarna lista + definicje w UCPD 2005/29 | Ex-ante: ocena naukowa + weryfikacja strony trzeciej |
| Ogólne hasła „eko/zielony” | Zakaz, chyba że **uznana wysoka efektywność ekologiczna** (EU Ecolabel / ISO 14024 typ I) | Szczegółowe wymogi dowodzenia art. 3 |
| Offset → „neutralny klimatycznie” | Zakaz **w każdych okolicznościach** (pkt 4c) | Offsety tylko jako informacja dodatkowa, oddzielona od emisji |
| Certyfikaty prywatne | Zakaz znaku bez systemu certyfikacji / organu publicznego | Nowe prywatne etykiety środowiskowe zasadniczo zakazane w UE |

W praktyce narzędzia anti-greenwashing od 27 września 2026 opierają się na **ECGT + prawie krajowym (UPNPR już teraz)**, a Green Claims traktuje się jako **wzorzec dobrej praktyki dowodowej**, nie jako obowiązek.

## Organy i sankcje (PL)

- **UOKiK** — art. 24 + art. 106 (do **10% obrotu za każdą praktykę**). Zarzuty: Allegro, DHL, DPD, InPost (VII 2025); Bolt, Tchibo, Zara (I 2026). Wytyczne urzędu o oświadczeniach środowiskowych — jeszcze nieopublikowane. Szczegóły: `11_praktyka_nadzorcza.md`.
- **Sądy cywilne** — B2C (UPNPR) i B2B (UZNK: odszkodowanie, zaniechanie, ogłoszenie).
- **KNF / ESA** — nadzór nad komunikacją produktów finansowych.
- **IJHARS / jednostki certyfikujące** — rolnictwo ekologiczne.
- **Organ CSDDD** (do wyznaczenia w PL) — kary do **3%** światowego przychodu netto (wg strony MRiT po Omnibus I).
