# Checklista weryfikacji komunikacji ESG

Używać przed publikacją etykiety, reklamy, strony, raportu, nazwy funduszu, oferty deweloperskiej, checkoutu e-commerce.

## Krok 0 — metryka twierdzenia

| Pole | Wpis |
|---|---|
| Dosłowne brzmienie + wizualia | |
| Kanał (opakowanie / ads / www / KID / social) | |
| Odbiorca (konsument / kontrahent / inwestor) | |
| Produkt, linia, firma, budynek, usługa? | |
| Sektor z mapy | FMCG / finanse / transport / moda / budownictwo / inny |
| Data i wersja dowodu | |

## Krok 1 — czarna lista ECGT (od 27.09.2026; wcześniej analogia UPNPR)

Odrzuć natychmiast, jeśli TAK:

- [ ] Własny znak „eco/sustainable certified” bez systemu strony trzeciej lub organu publicznego (**2a**)
- [ ] Ogólne hasło (eko, zielony, zrównoważony, climate friendly, green, Join Life, Conscious) bez uznanej wysokiej efektywności w **tym samym** kanale (**4a**)
- [ ] Claim o całości, dowód o fragmencie (**4b**) — greenlighting
- [ ] Neutralny / net-zero / climate positive **dzięki offsetom** (**4c**)
- [ ] Obowiązek prawny sprzedawany jako przewaga (**10a**)
- [ ] Fałszywa trwałość, naprawialność, ukryta wadliwość (**23f–j**)

## Krok 2 — test UPNPR (działa już teraz)

- [ ] Czy informacja jest prawdziwa?
- [ ] Czy prawdziwa informacja nie jest podana zwodniczo (art. 5 ust. 2 pkt 2)?
- [ ] Czy nie pominięto informacji, która zmienia znaczenie (art. 6)?
- [ ] Czy certyfikat/znak jest używany zgodnie z uprawnieniem (art. 7 pkt 2)?
- [ ] Czy przeciętny konsument z tego kanału zrozumie zakres?

## Krok 3 — dowód

Dowód musi pasować 1:1 do słów:

- zakres (produkt / część / działalność);
- metoda (norma, data, jednostka, granice);
- istotność (nie anegdota);
- porównanie (wobec czego „lepszy”?);
- strona trzecia, jeśli znak lub „zweryfikowane”;
- dane pierwotne vs. szacunek — ujawnione.

Wzorzec jakości (projekt Green Claims art. 3, nieobowiązkowy): nauka + LCA/istotność + brak szkody w innych obszarach + offsety oddzielone.

## Krok 4 — filtr sektorowy

**FMCG:** eko/bio = 2018/848; FIR art. 7; EUDR dla 7 towarów.  
**Finanse:** SFDR 8≠9; ESMA 80% + wykluczenia; taksonomia = alignment.  
**Transport:** liczba GHG = ISO 14083 / CountEmissionsEU; flota ≠ last mile.  
**Moda:** % włókna + certyfikat partii; CSDDD jeśli w zakresie; DPP.  
**Budownictwo:** EPBD art. 11 ≠ BREEAM/LEED; materiał → EPD.

## Krok 5 — spójność kanałów

- [ ] Front opakowania = tył = www = ads = raport ESG = wypowiedź CEO
- [ ] Nazwa produktu/funduszu = treść dokumentów
- [ ] Wizualia (liść, Ziemia, rower, wiatrak, zieleń tła) nie rozszerzają claimu ponad tekst — UOKiK: „nie kieruj się wyłącznie oprawą graficzną”
- [ ] Specyfikacja jest **w tym samym kanale** co hasło (FAQ ECGT); QR / „szczegóły na www” nie ratuje ogólnego 4a
- [ ] Old stock: od 27.09.2026 korekta online natychmiast; fizyczne opakowania — naklejka/POS, ewidencja, **bez niszczenia** (CPC)

## Krok 6 — sankcje (świadomość ryzyka)

| Ścieżka | Skutek |
|---|---|
| UOKiK art. 24 + 106 | Do 10% obrotu **za każdą praktykę**, choćby nieumyślnie; już stosowane (2025–2026) |
| UPNPR | Zaniechanie, odszkodowanie, zadośćuczynienie |
| UZNK | Roszczenia konkurentów |
| KNF / ESA | Interwencja nadzorcza przy produktach finansowych |
| CSDDD (gdy stosowane) | Do 3% światowego przychodu netto (MRiT) |

## Werdykt

- **Publikuj** — wszystkie checkboxy negatywne w kroku 1 puste, dowód 1:1, sektor OK.
- **Zawęź język** — dowód istnieje, ale węższy niż hasło (najczęstsza naprawa 4b).
- **Nie publikuj** — 2a, 4a bez Ecolabel, 4c, brak metodyki, certyfikat „z internetu”.
