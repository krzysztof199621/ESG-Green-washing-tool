# Słownik pojęć

| Termin | Znaczenie w tej bazie |
|---|---|
| Greenwashing | Komunikacja sustainability, która nie oddaje jasno i rzetelnie rzeczywistego profilu i może wprowadzać w błąd (definicja ESA). W B2C — nieuczciwa praktyka rynkowa. |
| Greenlighting | Wyróżnianie całego produktu/kolekcji/firmy na podstawie drobnego pozytywnego aspektu (ECGT 4b). |
| Ecoshaming (w praktyce UOKiK) | Potoczna „ekościema”: zielone hasło bez danych, skali i warunków; Prezes UOKiK używa obu etykiet w komunikatach 2025–2026. |
| Old stock | Opakowania/produkty z claimem sprzed 27.09.2026; CPC: korygować, nie niszczyć; online bez ulgi. |
| EAC / GO | Certyfikat atrybutu energii (energy attribute certificate / gwarancja pochodzenia); nie jest tożsamością z energią fizycznie dostarczoną — UOKiK vs Bolt. |
| Twierdzenie dotyczące ekologiczności | Dobrowolny komunikat handlowy o pozytywnym / zerowym / mniejszym / poprawionym wpływie na środowisko (ECGT). |
| Ogólne twierdzenie | Hasło bez specyfikacji w tym samym kanale („eko”, „zielony”). |
| Uznana wysoka efektywność ekologiczna | EU Ecolabel lub uznany ISO 14024 typ I lub najwyższy poziom z prawa UE. |
| System certyfikacji | Niezależna strona trzecia, publiczne kryteria, otwartość, sankcje, monitoring. |
| Offset / kompensacja | Kredyt GHG poza łańcuchem produktu; w ECGT **nie może** uzasadniać claimu „neutralny/pozytywny”. |
| EPD | Environmental Product Declaration — deklaracja LCA wyrobu (typowo EN 15804). |
| DPP | Cyfrowy paszport produktu (ESPR). |
| SFDR art. 8 / 9 | Promowanie aspektu E/S vs. cel zrównoważonych inwestycji. |
| Taksonomia alignment | Spełnienie istotnego wkładu + DNSH + minimum safeguards + TSC; nie mylić z eligibility. |
| DNSH | Do No Significant Harm — nie czyń poważnej szkody innym celom środowiskowym. |
| nZEB / budynek bezemisyjny | Niemal zero energii vs. definicja EPBD art. 11 (brak emisji kopalnych on-site + progi). |
| CountEmissionsEU | Rozp. 2026/1030 — wspólna metodyka GHG usług transportowych (ISO 14083). |
| EUDR | Rozp. 2023/1115 — produkty bez wylesiania, due diligence. |
| CSDDD / CS3D | Dyrektywa 2024/1760 — due diligence praw człowieka i środowiska w łańcuchu; po Omnibus I progi i terminy przesunięte. |
| ECGT | Dyrektywa 2024/825 Empowering Consumers for the Green Transition. |
| UCPD | Dyrektywa 2005/29/WE o nieuczciwych praktykach handlowych. |
| UPNPR | Polska transpozycja UCPD — ustawa o przeciwdziałaniu nieuczciwym praktykom rynkowym. Nowela ECGT: Sejm 4.09.2026, Senat druk 825, Art. 3 = 27.09.2027 (nieogłoszona). |
